
# Week 6 Assignment: Safe Tools

## Assignment Description
This assignment demonstrates Python error handling using try and except.

## Files

- safe_tools.py: Contains three functions for safe division, number conversion, and dictionary key lookup.
- README.md: Provides information about the assignment and its files.

## Question: Why can the if check not catch abc on its own?

An if statement can check conditions, but it cannot directly catch errors that happen when converting text into an integer. The try and except blocks handle the ValueError when the text is not a valid number.
